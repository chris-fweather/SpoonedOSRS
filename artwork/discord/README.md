# Spooned OSRS Discord artwork

Finished files:
- `../../public/brand/discord-invite-background.png`: 1920×1080 invite splash, with a quiet centre for the invite overlay.
- `../../public/brand/discord-server-banner.png`: 1920×1080 matching server banner, also used on the website Discord card.
- `server-banner-960x540.png`: compact server-banner export.
- `server-icon.png`: existing 1024×1024 Rocky server icon.

Use Spooned OSRS as the display name; SpoonedOSRS is the exact in-game name. Invite: https://discord.gg/spoonedosrs

Description: A home for Old School RuneScape pet collectors. Share your collection, compare your hunts and celebrate the next drop.

Art was created and revised using the built-in image-generation tool. The original outputs are preserved here; final sizes are mechanical PNG exports for Discord. The user's correction was applied to both backgrounds: Rocky uses the same faceted, non-pixelated style as the scenery.

Prompt: Old School RuneScape inspired low-poly fantasy dusk, charcoal stone castles, muted green pines, warm amber treasure and violet-blue sky. Rocky is a dark grey raccoon with black eye mask and striped tail. Invite composition: waterfall left, castle upper right, raccoon/chest lower right and calm dark centre. Banner composition: closer raccoon on chest lower right and calm upper quarter. No text, UI or logos. Edit: preserve all scenery and replace only the pixelated raccoon with a clean faceted illustrated raccoon matching environmental light and shadows.
