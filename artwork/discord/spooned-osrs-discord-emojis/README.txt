SPOONED OSRS - DISCORD EMOJIS

36 named icons (35 PNG + 1 animated GIF), all 128x128 with transparent backgrounds.
All visible artwork fits a centred 112px box with consistent padding. Original game pixel art is preserved.

START WITH 01_main:
pets = Rocky
clogs = collection log
quests = quest point star
diaries = achievement diary icon
leaderboard = three stat bars

02_more_icons contains the other distinct navigation, chat, quest/combat tier and rank sprites. Home reuses pets; Guides reuses clogs; Overview and Insights reuse leaderboard. These do not need duplicate emoji slots. rank_owner.gif includes the website Owner scimitar with its flowing lava effect: a seamless five-second animated loop. The complete display-rank set is rank_helper, rank_moderator, rank_admin, rank_owner and rank_gilded.

Unzip, then Server Settings > Emoji > Upload Emoji. Select the PNG and GIF files; filenames are valid Discord emoji names. Use the five main emojis in Server Profile > Traits.

This is the website UI/navigation pack, not the full pet/boss/item catalogue. No emoji has been uploaded automatically.

Source artwork: existing Spooned OSRS website assets sourced from the OSRS Wiki (https://oldschool.runescape.wiki), CC BY-NC-SA attribution as on the site; RuneScape artwork belongs to Jagex. See manifest.json for exact source paths.
