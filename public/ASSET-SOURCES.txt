Guide editor item icons (2026-10-07)
The guide editor offers every wearable, every Grand Exchange item and the collection log, quest and diary items, plus a short list of untradeable utility items and raid supplies (rune pouch, looting bag, raid potions). Names come from the OSRS cache (rev 241, https://github.com/abextm/osrs-cache, read with a local script following RuneLite's ItemLoader opcodes).
4,805 new inventory icons were added as items/{id}.png, one per item name:
- 4,517 from osrsreboxed-db (https://github.com/0xNeffarion/osrsreboxed-db, docs/items-icons/{id}.png, commit 37322fed3abb2d58236c59dfc6babb37a27a50ea, January 2025). These are 36x32 icons rendered from the game cache, like the RuneProfile icons above. The project README lists OSRS content as Jagex material outside its GPL code licence.
- 288 newer equipment icons from the OSRS Wiki team's DPS calculator (https://github.com/weirdgloop/osrs-dps-calc, cdn/equipment/*.png, matched by item id or, for the cargo crates and a few variants, by exact item name). These are the OSRS Wiki inventory images (CC BY-NC-SA).
All files passed PNG signature checks; none was generated, redrawn or resized. Items whose names repeat (for example the unobtainable Torva copies) share the icon of the variant that has one, through lib/guide-item-images.json, which also lists the six wearables with no icon anywhere (they are not offered in the editor). Newer non-equipment items without any published icon are left out of the editor.
Guide emojis reuse the site's Discord emoji pack sources (artwork/discord/emojis/manifest.json); no new files.

Empty equipment slot silhouettes (2026-10-07)
public/ui/slots/{head,cape,neck,weapon,ring,body,shield,legs,hands,feet,ammo}.png are the game's own empty worn-equipment slot sprites, decoded unchanged (32x32, transparent) from the OSRS cache (https://github.com/abextm/osrs-cache, commit ffb0cb0a343c1d6b9360595bb78314f60f923d03, "Cache version 2026-09-30-rev241"), index 8 (sprites), with a local script following RuneLite's SpriteLoader.
