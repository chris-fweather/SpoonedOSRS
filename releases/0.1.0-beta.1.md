# Spooned OSRS 0.1.0-beta.1

First beta · 7 October 2026

This is the first version deployed for beta testers. It builds on release candidate 0.1.0-rc.4 and fixes the problems testers hit when signing in and syncing.

## For players

- Refreshing your stats works again. Every OSRS Hiscores, RuneProfile, TempleOSRS and Wise Old Man refresh was failing with an "Invalid redirect value" message; all four sources now update.
- A refresh that fails no longer makes you wait a minute before trying again. The one-minute pause only starts after a refresh is saved. Searching for your own name before signing in no longer delays your first refresh either.
- Error messages are now plain and actionable. Internal errors show a short "please retry" message instead of technical text.
- Each Discord account can link up to 10 RuneScape names, including names you unlinked. Ask staff if you need one released.

## Behind the scenes

- Every pull request now signs in with Discord, claims a name and runs a full refresh against the real build, with Discord and the game data sites simulated.
- After each deploy, a signed check fetches real data from all four sources through the live site without saving anything. It becomes active once `DEPLOY_CHECK_SECRET` is configured; until then the deploy prints a warning.
- Database, Discord and owner identifiers come from Cloudflare build variables instead of source code. HTTPS is now enforced with HSTS, and a build-tool dependency was updated.

No database migration is required beyond `0021_provider_controls.sql`. Name linking still does not prove RuneScape account ownership.
