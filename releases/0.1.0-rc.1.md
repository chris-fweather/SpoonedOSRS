# Spooned OSRS 0.1.0-rc.1

Release candidate · 7 October 2026

This candidate brings pet tracking, account progress and community tools into a
versioned release process. It is not a stable launch announcement. Features in
these notes are present in the candidate source; availability on the live site
depends on deployment.

## Player experience

- Track pet acquisition dates, methods and personal planning rates.
- Record dates for collected log items and explore dated collections on a
  timeline with pet/log filters, image markers, zoom and pan.
- Browse compact community leaderboards and expanded player progress.
- Manage linked accounts, per-account visibility, titles, emblems and character
  appearance. Character loading and mobile layouts have been refined.
- Place character meshes inside original 3D profile environments with optional
  environmental movement and reduced-motion support.

## Community and staff

- Write structured guides with supported headings, equipment and inventory
  setups, requirements and probability charts.
- Manage unlink/relink requests with role-based review, case notes and account
  action history. Protected accounts require admin review.
- Allow admins to correct recorded pet progress with a reason, confirmation,
  revision checks and an audit record.
- Prepare a separate Discord role-sync service. It requires configuration and
  activation; publishing this website does not activate the bot.

## Reliability

- Exclude unexpected legacy import metadata from visitor responses.
- Add production browser security headers and validate real acquisition dates.

- Query leaderboard summary data rather than scanning whole journals.
- Share upstream API pacing, response caches and cooldowns across site users.
- Preserve saved progress when an upstream service is unavailable or limited.
- Verify versions, TypeScript, unit tests, database migrations and the production
  build through a single release command.

## Database and operations

Requires migrations through `0021_provider_controls.sql`. Existing production
installations must apply missing migrations in order before this code runs.
New tables cover Discord preferences, moderation cases and upstream controls.
Use the deployment and rollback procedure in `docs/releases.md`.

## Known limitations

- No RuneScape character emotes, individual combat-task sync, guide maps or
  account-aware pathfinding in this candidate.
- The collection timeline uses recorded acquisition dates. Historical XP
  timelines and reconstructed historical drop odds are not implemented.
- API/model permissions, dependency findings and representative launch-load
  testing still need closure before a stable public launch.
- The working repository remains private. A source licence and a sanitised,
  independently reviewed public snapshot are separate release requirements.
- Donation-linked game artwork and redistributed game-derived models are not
  represented as approved by Jagex.

## Validation

The candidate release command runs type checking, the complete unit suite,
fresh-database and upgrade migration checks, and a production build. Local
browser and moderation API checks supplement those automated checks. This is
not a security certification or a measured concurrent-user capacity guarantee.
