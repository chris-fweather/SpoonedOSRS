# Spooned OSRS 0.1.0-rc.3

Mobile collection navigation candidate · 7 October 2026

Leaderboard totals now scale to their available column width while retaining every digit. The skill filter follows the search field on its right. Collection-log previews open with category tiles, then searchable, paginated boss/activity tiles with progress bars. Selecting a collection opens its items with back navigation and any recorded collection dates in the hover.

Profile refresh callbacks use the existing all-source sync, matching Connections → Refresh all sources. Provider coverage and permission boundaries are unchanged. Staff-portal design changes are deferred.

GitHub verification has a 4 GB Node heap for clean TypeScript checks; generated compiler caches are no longer tracked. No new database migration is needed. This remains a candidate, with the launch-readiness limitations documented in the earlier release review.
