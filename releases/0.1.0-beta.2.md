# Spooned OSRS 0.1.0-beta.2

Second beta · 7 October 2026

This beta makes the first search for a name show everything public about it, rebuilds leaderboard previews for phones, and adds automated checks for the staff tools.

## For players

- Search any RuneScape name, without signing in, and the site pulls OSRS Hiscores, RuneProfile, TempleOSRS and Wise Old Man at once. The profile shows stats, the collection log, pets, quests, diaries and combat achievements straight away. Claim the name with Discord to refresh it yourself from then on.
- Tapping a player on a leaderboard shows the same three summary cards on every board and one summary row underneath, then opens that board's own category: skills, pets, collection log, combat achievement tiers or quests.
- The collection log preview has a category dropdown beside search, and each collection opens with its icon, progress and in-game style item slots. Pets use the same slots.
- Top-ranked skills glow bronze, silver or gold like ranked bosses, and the rank #1 record holder gets a crown.

## For staff

- Requests from other websites that try to change data are refused with a clear 403 everywhere. They were always blocked; some routes reported them as a save error.

## Behind the scenes

- Every pull request and release now runs the staff ranks, moderation, guides, privacy, account, commendation, pet record, import and share-card checks against the production build, alongside the Discord login and sync flow.
- A live site check runs after every deploy and every six hours. With `DEPLOY_CHECK_SECRET` set in GitHub it also runs a signed, read-only sync against all four sources.
- Searched names are stored in a compact public format (`public-sources-v2`) that keeps the collection log and progress without per-player catalogue text. Older searched names upgrade the next time they are looked up.

No database migration is required beyond `0021_provider_controls.sql`. Name linking still does not prove RuneScape account ownership.
