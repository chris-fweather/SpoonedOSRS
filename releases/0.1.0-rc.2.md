# Spooned OSRS 0.1.0-rc.2

Mobile polish candidate · 7 October 2026

Staff workspaces now use labelled, grouped navigation on desktop and a collapsible section menu on phones. Staff accounts get a shield shortcut in the main navigation, outside their account dropdown. Account requests include a destination-account search by Discord username, exact ID or linked RuneScape name. Search remains restricted to moderators and above; existing case protections and approval rules are unchanged.

Leaderboard rows use three columns: position, player identity and total. Follower pets have been removed from ranking rows; player names, rank icons, supporter suffixes and achievement titles remain. The castle scene now includes an arched gatehouse, watchtowers, masonry courses, banners, torches and planted courtyard borders.

No new database migration is required beyond 0021_provider_controls.sql. Existing Discord OAuth and source import behavior are unchanged. RuneProfile and Temple supply shared collection data; Wise Old Man supplies tracked skills and boss counts.

Validation includes TypeScript, the unit suite, moderation integration checks with added account-search assertions, and responsive browser checks. This remains a candidate; unresolved launch readiness and dependency findings from the prior review still apply. The repository remains private.
